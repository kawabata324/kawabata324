## 🚀 いま作っているもの — 買取カメラ

リユース・買取店向けの **AI査定アシスト**。カメラをかざすだけで相場・推奨買取価格・粗利を提示し、
成約から古物台帳の記帳までを一気通貫で自動化します。

| 📦 **LP ソースコード** | [kawabata324/kaitori-camera-lp](https://github.com/kawabata324/kaitori-camera-lp) |
