## 🚀 Products（個人開発）

### 買取カメラ — リユース・買取店向け AI査定アシスト

カメラをかざすだけで相場・推奨買取価格・粗利を提示し、成約から古物台帳の記帳までを一気通貫で自動化します。

| | |
|---|---|
| 🖥 **プロダクト（本体アプリ）** | <https://genka-camera.vercel.app> |
| 🌐 **紹介LP** | <https://kaitori-camera-lp.vercel.app> |
| 📦 **LP ソースコード** | [kawabata324/kaitori-camera-lp](https://github.com/kawabata324/kaitori-camera-lp) |

> LP は **Astro + Tailwind CSS v4** で構築。Screen Studio 風のプロダクト動画枠を備えた B2B SaaS デザインです。

### Shadowverse Vision — 競技シーンの非公式まとめ

デジタルカードゲーム『Shadowverse: Worlds Beyond』の公式大会 *Premier Series* を追う非公式まとめサイト。
試合日程・結果、チーム順位、選手成績、レートランキング、配信状況、デッキ環境などを集約しています。

|---|---|
